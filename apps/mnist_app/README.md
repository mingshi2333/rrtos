# MNIST App

`apps/mnist_app` is the canonical supported AI application in `rrtos`.

## What it contains

- `src/main.c` - simple runtime loop example
- `src/validation_main.c` - supported runtime validation entrypoint
- `src/validation.c` - shared validation helpers
- `src/mnist_validation_samples.h` - committed five-sample MNIST batch used by runtime regression
- `generated/` - generated model wrappers and descriptors

## Build

```bash
pixi run -e rv32 configure
pixi run -e rv32 build
```

## Canonical validation

Run the supported QEMU gate:

```bash
pixi run -e rv32 validate-mnist-runtime
```

Run the optional Renode observation lane:

```bash
pixi run -e rv32 observe-mnist-runtime-renode
pixi run -e rv32 compare-mnist-runtime-platforms
```

## Validation behavior

The validation target:

- initializes the canonical registry runtime
- loads `st_mnist_28`
- runs a five-sample batch from the official MNIST `t10k` test set
- checks committed output fingerprints for drift
- prints label notes when the current model argmax differs from the dataset label

The sample fixture is generated by `scripts/generate_mnist_validation_samples.py` and stored in `src/mnist_validation_samples.h` so CI does not need network access.
